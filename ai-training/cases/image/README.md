# 圖片案例放這裡

每張圖片建立一個 JSON。範例：

```json
{
  "id": "image-001",
  "type": "image",
  "image": {
    "path": "../../images/image-001.jpg",
    "detail": "high"
  },
  "lines": [
    {
      "original": "",
      "normalized": "1819212934 二x1 三x1 四x1",
      "confidence": 0.95
    }
  ],
  "warnings": []
}
```
