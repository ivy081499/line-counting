CREATE TABLE friends (

    name TEXT NOT NULL UNIQUE,

    created_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (raw_message_id) REFERENCES raw_messages(id),

    朋友管理：
    
    - 朋友管理 submenu 目前有：
        - 新增朋友
        - 查看朋友列表
        - 刪除朋友
    - 新增朋友：
        - 點一次「新增朋友」後，進入連續新增模式。
        - 連續新增模式中，每一則普通文字都新增為朋友名稱。
        - 新增朋友不會改變目前選定朋友。
        - 新增朋友不會和目前已選朋友建立任何關聯。
        - 朋友名稱不可重複。
        - 若朋友已存在，回覆已存在，且仍維持連續新增模式。
        - 使用者點其他 Rich Menu 功能時，才離開新增朋友模式。
    - 刪除朋友：
        - 必須軟刪，不可硬刪。
        - 只設定 friends.deleted_at。
        - 不刪 raw_messages。
        - 不刪 parsed_entries。
        - 刪除前要二次確認。
        - 軟刪朋友不出現在選朋友/刪除朋友清單。
        - 如果同名朋友之後再次新增，應恢復原本軟刪朋友，把 deleted_at 設回 NULL。
        - 刪除朋友後，要清掉所有目前選到該朋友的 user_sessions.current_friend_id。

    - Worker 先回 Flex Message 朋友選單。

    支數計算邏輯：
    
    名詞：
    
    - 每位朋友傳來的下注內容叫「注單」。
    - 注單可能是一則 LINE 文字，也可能未來由圖片 OCR 產生文字。
    - 一則注單可能有多行。
    - 每一行是一組要解析的下注資料。
    - 用 x / X / . 分隔後的單位叫「排」。
    
    注單範例：
    0102x0304x0506 兩三x0.5
    0102030405 兩x1
    
    號碼區：
    
    - 每行左邊是號碼區。
    - 號碼永遠兩位數切一個。
    - 010203 => 01、02、03。
    
    分排規則：
    
    - x、X、. 都是分排符號。
    - 0102x030407x0506 表示 3 排：
    第1排：01、02
    第2排：03、04、07
    第3排：05、06
    
    沒有分排符號時：
    
    - 每個兩位數各自一排。
    - 0102030405 表示 5 排：
    01 / 02 / 03 / 04 / 05
    
    規則區：
    
    - 每行右邊是規則區。
    - 例如：
    二x1
    兩x1
    三x0.5
    二三x1
    兩x0.5 三x1
    
    中文數字：
    
    - 二、兩 都代表 2
    - 三代表 3
    - 四代表 4
    - 之後可擴充五、六等
    
    真正要算的是「支數」，不是單純 Cn 取 m：
    
    1. 先解析號碼區，得到多排。
    2. 規則 m 表示從所有排中選 m 排。
    3. 對每一種被選中的排組合，計算各排內號碼數量的乘積。
    4. 把所有排組合的乘積加總。
    5. 再乘上倍率。
    
    已驗證案例：
    
    - 0102x0304 二x1 => 二4
    - 010203x040506 二x1 => 二9
    - 010203x040506x070809 二三x1 => 二27、三27
    - 0102x030407x0506 兩x0.5 三x1 => 二8、三12
    - 0102030405 兩x1 => 二10
    - 0102.0304 二x1 => 二4
